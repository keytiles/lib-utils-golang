## TLDR

- Placeholders use Python-style `{name}` syntax; names match `[a-zA-Z0-9_]+`.
- `StringSimpleResolve` substitutes placeholders from a `map[string]any`; missing keys (or a nil map) leave the placeholder unchanged.
- `StringExtractVariableNames` returns the unique variable names found in a string as a `*kt_sets.Set[string]`.
- Both helpers share `VARIABLE_MATCHER`.

## How it works

- Helpers live in package `kt_utils`.
- Matching is done with the package-level regex `VARIABLE_MATCHER`: `\{([a-zA-Z0-9_]+)\}`.
- Only simple brace placeholders are recognized — not `${name}`, not nested braces, not dotted paths.

### StringSimpleResolve

- Signature: `StringSimpleResolve(input string, vars map[string]any) string`
- For each match, looks up the captured name in `vars`.
- If present, replaces the whole `{name}` with `fmt.Sprint(val)` (works for strings, numbers, bools, etc.).
- If absent (or `vars` is nil), leaves `{name}` as-is in the result.
- Repeated occurrences of the same name are each resolved independently.

### StringExtractVariableNames

- Signature: `StringExtractVariableNames(s string) *kt_sets.Set[string]`
- Finds all matches and adds the captured names to a new set (capacity hinted from match count).
- Duplicates collapse to one entry (set semantics).
- Order of elements is undefined (set / map-backed).

### VARIABLE_MATCHER

- Exported `*regexp.Regexp` used by both helpers.
- Public so callers can reuse the same placeholder grammar if needed; changing it would change both resolve and extract behavior.

## API surface

- `VARIABLE_MATCHER` — `*regexp.Regexp` for `{name}` with `name` = `[a-zA-Z0-9_]+`
- `StringSimpleResolve(input string, vars map[string]any) string` — resolve placeholders; missing keys unchanged
- `StringExtractVariableNames(s string) *kt_sets.Set[string]` — unique variable names in `s`

## Usage sketch

```go
import (
	"github.com/keytiles/lib-sets-golang/v2/pkg/kt_sets"
	"github.com/keytiles/lib-utils-golang/v2/pkg/kt_utils"
)

tpl := "My name is {name} I am {age} years old. I live in {place}"
vars := map[string]any{"name": "Attila", "age": 50}

resolved := kt_utils.StringSimpleResolve(tpl, vars)
// "My name is Attila I am 50 years old. I live in {place}"

names := kt_utils.StringExtractVariableNames(
	"This is a text with {var1} and {var2} variables. And we repeat {var1} again",
)
same := names.Equals(kt_sets.NewSet("var1", "var2")) // true

_ = resolved
_ = same
```

## Caveats

- **Placeholder grammar is strict.** `{user.name}`, `{with-dash}`, empty `{}`, or `${env}` are not matched.
- **Values are stringified with `fmt.Sprint`.** Structs and pointers get Go’s default formatting unless you pre-format them in the map.
- **Nil or incomplete maps do not error** — unresolved placeholders remain in the output.
- **Extract returns a set**, not an ordered list and not occurrence counts.
- **`VARIABLE_MATCHER` is shared state.** Do not replace or mutate it at runtime if other goroutines may be resolving/extracting concurrently.
