## What is this for?

You want a **readable dump** of a value (often a struct) in a log line — but you do **not** want to pay for building that string when the log level drops the line.

`VarPrinter` wraps the value and implements `fmt.Stringer`. The dump is built only when the logger actually formats `%s`.

This page is inspiration and a foot in the door — not a full reference. For dispatch rules and API surface, see the technical doc linked above.

## 1. The basic pattern (start here)

```go
import "github.com/keytiles/lib-utils-golang/v2/pkg/kt_utils"

type Order struct {
	Id     string
	Amount int
}

order := Order{Id: "ord-1", Amount: 42}

// Good — dump built only if DEBUG is enabled / the line is emitted
LOGGER.Debug("order: %s", kt_utils.VarPrinter{TheVar: order})
```

Avoid building the string yourself in the argument list:

```go
// Bad for logs — PrintVarS always runs, even if the line is dropped
LOGGER.Debug("order: %s", kt_utils.PrintVarS(order, false))
```

Use `PrintVar` / `PrintVarS` when you **always** want the dump (tests, ad-hoc debug, non-log paths).

## 2. Multi-line dump

```go
LOGGER.Debug("order: %s", kt_utils.VarPrinter{
	TheVar:      order,
	PrettyPrint: true,
})
```

Compact one-liner is the default (`PrettyPrint: false`).

## 3. Text payloads as `[]byte`

If you have JSON or plain text in a `[]byte`, do **not** convert at the call site:

```go
payload := []byte(`{"id":"ord-1"}`)

// Bad — string(payload) runs eagerly
LOGGER.Debug("payload: %s", kt_utils.VarPrinter{TheVar: string(payload)})

// Good — conversion only if the line is emitted
LOGGER.Debug("payload: %s", kt_utils.VarPrinter{
	TheVar:        payload,
	BytesAsString: true,
})
```

Without `BytesAsString`, raw `[]byte` dumps as litter’s `[]uint8{...}` — fine for binary, noisy for text.

## 4. Lazy prepare / secret masking (`Transform`)

Masking (or any copy/reshape) in your service is often expensive. If you mask **before** wrapping, you pay even when the log is dropped:

```go
// Bad — MaskSecrets always runs
LOGGER.Debug("cfg: %s", kt_utils.VarPrinter{TheVar: MaskSecrets(cfg)})
```

Defer it with `Transform`:

```go
LOGGER.Debug("cfg: %s", kt_utils.VarPrinter{
	TheVar: cfg,
	Transform: func(v any) any {
		return MaskSecrets(v) // your service helper; runs only if formatted
	},
})
```

`Transform` can return the same type or a different shape — whatever you want dumped afterwards.

## 5. Type-owned log form (`LogStringer`)

Sometimes the **type** should decide how it looks in logs, separately from `fmt.Stringer` / normal dumps.

```go
type ApiClientConfig struct {
	BaseURL string
	APIKey  string
}

func (c ApiClientConfig) String() string {
	return fmt.Sprintf("ApiClientConfig{BaseURL:%s}", c.BaseURL)
}

func (c ApiClientConfig) LogString() string {
	// safe / redacted form for logs
	return fmt.Sprintf("ApiClientConfig{BaseURL:%s, APIKey:***}", c.BaseURL)
}
```

- Logging path: `VarPrinter` prefers `LogString()` when implemented.
- Ad-hoc dump: `PrintVarS` still uses `String()` / litter — it **ignores** `LogStringer`.

```go
cfg := ApiClientConfig{BaseURL: "https://api.example", APIKey: "secret"}

LOGGER.Debug("cfg: %s", kt_utils.VarPrinter{TheVar: cfg}) // LogString()
_ = kt_utils.PrintVarS(cfg, false)                         // String(), not LogString()
```

## 6. Putting pieces together

Typical “log this config safely and lazily” shape:

```go
LOGGER.Debug("request context: %s", kt_utils.VarPrinter{
	TheVar:      reqCtx,
	PrettyPrint: true,
	Transform: func(v any) any {
		return MaskSecrets(v)
	},
})
```

Or lean on `LogStringer` on the type and keep the call site tiny:

```go
LOGGER.Debug("cfg: %s", kt_utils.VarPrinter{TheVar: cfg})
```

`BytesAsString` still works after `Transform` if the transform returns a `[]byte` text payload.

## Quick “which should I use?”

- **Log line, maybe dropped by level** → `VarPrinter{TheVar: …}`
- **Always need a string now** (test assertion, CLI) → `PrintVarS`
- **Text in `[]byte`** → `BytesAsString: true` (not `string(bytes)` in the literal)
- **Expensive prepare / mask** → `Transform` on `VarPrinter` (not call-site prepare)
- **Type knows its safe log form** → implement `LogStringer`; dump via `VarPrinter`
